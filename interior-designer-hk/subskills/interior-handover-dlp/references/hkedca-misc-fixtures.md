# HKEDCA — Miscellaneous Works (雜項工程)

Source: `HKEDCA §雜項/*`, PDF ~p.142–151.

## Scope

Final-install items after main trades: sanitaryware, lighting, switch plates, window sill stone, small hardware.

## Sanitaryware (潔具安裝)

- Install after waterproofing and wall/floor finishes complete in wet rooms.
- Check level, sealant continuity, water test where specified.
- Protect chrome and ceramic until handover cleaning stage.

## Lighting (燈具)

- Install after ceiling paint/false ceiling completion unless early mock-up required.
- Coordinate switching with electrical rough-in and face plates.
- Verify earthing and test before cover plates.

## Switch plates (掣面)

- Install after paint cure; align gangs level; no paint on plates.
- Match approved schedule and fire-rated requirements where applicable.

## Window sill stone (窗檯石)

- Install with proper bedding; protect edges (pearl cotton + boards) until handover.
- Silicone seal to frame; check slope to drain if exterior sill.

## Small hardware (小五金)

- Install late programme (aligned with 清拆 protection rule for doors).
- Confirm fixing substrate (tile, timber, stone) and corrosion resistance in wet zones.

## Measurement (工程計算規則)

- Count nr for each fixture type; stone sills by length or area per contract.
- Include sealant, connectors, and standard accessories in unit rate unless BOQ separates.

## Handover cross-check

All miscellaneous items appear on **交收** room-by-room list before practical completion recommendation.
