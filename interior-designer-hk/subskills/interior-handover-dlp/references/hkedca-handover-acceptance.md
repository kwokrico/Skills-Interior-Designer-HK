# HKEDCA — Handover & Acceptance (交收)

Source: `HKEDCA §交收/*`, PDF ~p.152–177.

## Pre-handover preparation (驗收前準備)

- Complete all trades; masonry snag (坭水執爛) closed.
- Protection removed only when safe for cleaning.
- Keys, manuals, warranties collated per contract.

## Cleaning sequence (清潔先後次序)

1. Masonry snag fix (坭水執爛)
2. Internal tile clean (內隴清潔)
3. External clean (外層清潔)
4. Fine internal tile clean (內隴幼清): flat joints, clean corners, **approved cleaners only**

### Rough clean (粗清) — notes

- Adequate water supply or permanent tile damage risk.
- Secure hose; proper drainage; lift pits sandbagged.
- Water-sensitive joinery and switches installed **after** rough clean.
- Remove protection tape immediately after rough clean if no longer needed.
- Protect bath/basin chrome drains with alkali oil during clean; rinse promptly.

### Fine clean (幼清)

- Only after masonry snag, fixtures, and kitchen install complete.
- Lock unit door; **no detergents/water flood** — damp cloth on installed surfaces.

### General packaging clean

- Large debris → vacuum → room-by-room (bath + living parallel).
- **Outside-in, top-down, inside-out**; adequate lighting; shoe covers; padded ladder feet.
- Window sill: dry paper pad before stone clean; aluminium cleaner on frames; glass with water squeegee, check for grit.

## Acceptance methods (驗收方法及標準) — HKEDCA §交收/5

| Method | Application |
|---|---|
| Visual (目測) | All visible surfaces, paint, finishes |
| Sound (耳聽) | Tap walls — hollow plaster, loose render, delaminated paint |
| Touch (手觸) | Nail-scrape paint for adhesion |
| Smell (嗅覺) | Blocked drains, mould, spoiled paint |
| Foot (腳踏) | Timber floor looseness |
| Level (平水尺) | Floors, stone, sills, door frames where slope visible |
| Water test (灑水) | Shower screens, windows (with management approval), tiles/stone if leakage suspected |

## Acceptance checklist highlights (驗收項目)

### General cleaning

- Floor drains clear; no grout on tile faces; sealant neat; no stains/pencil marks; glass/mirror clean; no construction debris.

### Plaster (批盪)

- Hollow test grid ≤300 mm; repair rules for square/rectangular hollow areas per guide tables.
- Tolerances (typical): verticality, flatness, corner squareness, joint straightness **3–5 mm** (check with straightedge/water level).

### Timber flooring

- Adjacent boards: level diff ≤1 mm; gap ≤1 mm; no exposed nails; no hollow when walked; lacquered surface dust-free; flatness ≤5 mm per 100 ft².

### Doors/windows

- Smooth operation; hardware complete; seals continuous; frames plumb; glass undamaged.
