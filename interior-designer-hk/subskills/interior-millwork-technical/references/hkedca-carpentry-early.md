# HKEDCA — Early Carpentry (木工工程前期)

Source: `HKEDCA §木工前期/*`, PDF ~p.98–108.

## Scope

Rough carpentry before final finishes: light troughs, curtain boxes, AC casings, false ceilings (假天花).

## General rules

- Coordinate with MEP routes before closing ceiling.
- Use clean gloves for false ceiling install and maintenance to avoid fingerprints.
- Set out from coordinated RCP; maintain access panels for valves and dampers.

## Light trough (燈槽)

- Size for specified luminaire + driver clearance + ventilation.
- Fire-rated board where required; maintain sprinkler throw clearance.
- Chain to `interior-lighting-science` and `interior-mep-clash-detection`.

## Curtain box (窗簾殼)

- Allow track depth, stack-back, and pelmet services.
- Fix securely to structure; avoid sole reliance on plasterboard where load heavy.

## AC casing (冷氣機殼)

- Align with equipment schedule and refrigerant pipe drop.
- Access for maintenance and condensate drain slope.
- Coordinate external wall sleeve with window replacement programme if applicable.

## False ceiling (吊頂/假天花)

- Level grid; hanger spacing per board manufacturer.
- Penetrations for sprinklers, detectors, diffusers — coordinate with fire and MEP.
- Leave demountable zones at valves and junction boxes.

## Programme position

```
MEP rough-in → early carpentry (ceiling framing) → plaster/tile in wet areas → paint → late joinery
```

## Measurement

- m² for ceiling area; nr for boxes/troughs; state height band and access panel count.
