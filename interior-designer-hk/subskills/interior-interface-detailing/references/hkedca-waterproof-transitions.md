# HKEDCA — Waterproof & Wet/Dry Transitions

Sources: `HKEDCA §坭水/4`, `§木工後期` bathroom frame notes, `§清拆/2.2`, PDF ~p.8–9, 88+, 129+.

## Wet zone continuity

- Membrane upturn at walls and door thresholds before floor finish.
- Bath/shower door frame: seal gap between frame and jamb with **waterproof sealant ~1.5 m height** at bathroom door per late carpentry practice.
- Bathtub recess: optional **20 mm × 900 mm** notch in false frame at tub side for installation — patch included in install rate if contract silent.

## Tile/stone interface protection → detail implications

| Condition | Detail intent |
|---|---|
| Wall tile in traffic route | Protect corners; specify metal or PVC trim at external corners |
| Floor tile before cover | No cutting on laid tiles; clean before protection boards |
| Stone edges | Pearl cotton + boards on projecting edges and window sill nosing |

## Level and threshold

- Resolve wet-to-dry level change at doorway with threshold profile or step-down — coordinate thickness build-up.
- Door frame install only after screed recess formed; frame plumb within contract tolerance.

## Failure modes

| Failure | Typical cause |
|---|---|
| Leak at threshold | Membrane discontinuity or early trafficking |
| Staining on stone | Inadequate edge protection during trades |
| Hollow tile | Premature loading on screed |
