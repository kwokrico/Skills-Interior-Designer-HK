# HKEDCA — Site Protection Matrix (保護)

Source: `HKEDCA §清拆/2.1–2.2`, PDF ~p.7–12.

## Protection purposes

1. Reduce snag/rework (執漏); protect building quality.
2. Avoid programme delay and cost overrun.
3. Inadequate protection forces redo (e.g. window replacement → hack finished reveals; facade tile colour mismatch).

## Principles (保護的原則)

1. Deliver materials to site aligned with programme — avoid early damage.
2. Install damage-prone items **late** where possible.
3. Except main entrance and kitchen door, **other doors late in programme**.
4. Maintain existing protection — do not remove prematurely.

## Types

| Type | Application |
|---|---|
| Temporary | Factory/transport; during works; after completion until handover |
| Permanent | Design-integrated (e.g. corner guards) |

| Category | Requirements |
|---|---|
| During construction | Protect completed trade before next trade enters; avoid blocking circulation |
| After completion | Protect lift lobby stone, walls, door frames, lift cars, external corners; transparent film acceptable |

## Element-by-element matrix

| Element (中文) | Protection requirement | Failure consequence |
|---|---|---|
| 窗框 Window frame | Keep factory film; repair tears; remove film only after all works | Major rework if replaced |
| 防水 Waterproofing | Barriers + signage; no foot traffic; pave floor soon after cure | Large rework; leak liability |
| 木門框 Timber door frame | Plywood cover; small nails in architrave zone; fix with masonry quickly; fire/water notes | Frame warp, rework |
| 盪地台 Screed | Barriers while wet; avoid splash on walls; load only at design strength; pad materials on finished plaster | Cracking, level failure |
| 牆身瓦 Wall tile | Soak tiles in designated tub; protect finished walls/corners in traffic routes | Chip, stain |
| 地台瓦 Floor tile | No cutting on laid tiles; barrier if no bearing capacity; clean before covering with boards | Scratch, hollow sound |
| 雲石/麻石 Stone | Clean immediately; film + boards/pearl cotton on edges | Full slab replacement risk |
| 油漆 Paint | Protect other trades first; canvas on floors; "油漆未乾" sign; ventilation; close windows before rain/off shift | Rework, odour claims |
| 窗玻璃 Glass | Store flat, ventilated, separated; install **after** scaffold removal; clean without grit | Replacement |
| 廚櫃 Kitchen cabinets | Store on battens; film + pearl cotton + boards; no walking on tops; doors/hardware last | Cascade removal if sink damaged |
| 木地板 Timber floor | Only after windows glazed; seal wet-room door gaps before sanding; limit traffic; paper + rubber-foot ladders | Swell, mould |
| 木門 Timber door | Wedge gap after hang; pearl cotton for hardware install | Full door redo if solid colour damaged |
| 假天花 False ceiling | Clean gloves for install/maintenance | Visible fingerprints |
| 機電 MEP | Room finishes before plant install; indoor dry storage; layer pipes; pad all stacks; wall devices after tile wash; tape penetrations | Damage, contamination |
| 消防 Fire | Sprinkler guards; detector caps; valve protection; escape sign film; **掛牌** isolate alarm before fire works | False alarm, damage |
| 電器 Electrical | Cover panels after test; secure unused cable ends; warning labels on live gear | Meter/instrument damage |
