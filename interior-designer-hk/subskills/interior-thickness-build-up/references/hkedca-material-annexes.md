# HKEDCA — Residential Material Annexes (坭水附件)

Source: `HKEDCA §坭水` annexes (住宅標準用料表, 標準防水用料表), PDF ~p.75–97.

## Purpose

Standard material lists for typical HK residential fit-out — use for BOQ checking and substitution control, not as sole spec without designer approval.

## Cement:sand screed (英坭沙) — control points

| Parameter | Verify in spec |
|---|---|
| Mix ratio | e.g. 1:3 or project-specific |
| Minimum thickness | Per structural and finish stack |
| Curing time | Before tile or load |
| Falls | Wet room % slope to drain |

## Standard waterproof system stack (conceptual)

| Layer | Function |
|---|---|
| Primer | Substrate bonding |
| Main membrane | Continuous wet-area barrier |
| Reinforcement tape | Corners, pipes, joints |
| Protection layer | Before tile if required by manufacturer |
| Finish tile/stone | After test |

## Residential finish material table — use in QA

When tendering or procuring, cross-check:

- Tile body type and slip rating for wet areas.
- Adhesive class compatible with substrate and tile size.
- Grout type (standard vs epoxy for wet/heavy duty).
- Sealant at movement joints and wet-to-dry boundaries.

## Substitution rule

Any change from annex baseline requires:

1. Performance equivalency note (waterproof, bond, slip).
2. Thickness delta check → `interior-thickness-build-up`.
3. Interface detail update → `interior-interface-detailing`.
