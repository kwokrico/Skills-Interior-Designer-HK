# HK residential starter defaults (typical first pick / or equal)

Use as **suggested first picks** on new schedules. Always phrase as 「品牌（或同等）」. Confirm availability, dye lot, and showroom stock per project. **Do not** lock supplier phone numbers or URLs from a past job into the schedule as mandatory contacts.

| Category | Code hint | Typical first pick | Notes |
|----------|-----------|--------------------|-------|
| SPC floor (dry living/bed) | FL | Cockatoo stone-look SPC (or equal); wear layer ≥0.5 mm; total ~5.0–5.5 mm | Alternates: Quick-Step etc. Confirm underlay / moisture membrane |
| Skirting | SK | Match SPC or painted MDF/HPL | Wet rooms: tile skirting or upstand |
| Alu false ceiling (kitchen/bath) | CL | Hunter Douglas-type 300 mm strip (or equal), ≥0.6 mm | Prefer strip over lay-in unless drawings change |
| Gypsum false ceiling / cove | CL | Knauf / Gyproc (or equal) per BS EN 520 | Keep driver/access for cove lighting |
| Carcass plywood | CB-PLY | E1/E0 moisture-resistant plywood 18 mm; wet zones prefer HMR | No unsealed particleboard on exposed edges |
| Face HPL | CB-HPL | Formica (or equal: LAMITAK / Wilsonart) | Request formaldehyde evidence with board |
| Kitchen solid surface | CT | Corian (or equal: Staron / Lexton-class) | Quartz substitute needs drawing/tender update |
| Bath vanity stone | CT | Compact quartz (COMPAC-class or equal) / Corian | Prefer quartz in wet vanities |
| Threshold / sill stone | TH / WS | Same quartz family as vanity where possible | Unify colour with SPC |
| Emulsion paint | PT | Dulux washable / low-odour (or equal: Nippon / Jotun) | Low-VOC; SDS on request |
| Feature art paint | PT | Oikos / Novacolor (or equal) | Coordinate with base PT colour |
| Soft-close joinery HW | HW | Blum (or equal: Hettich) | Soft-close hinges + full-extension runners |
| Door HW (non-FD) | DH | 304 SS or zinc alloy; brushed/matt | FD doors need certified sets |
| Sanitaryware | SW | TOTO (or equal: American Standard) | Confirm rough-in on site |
| Mixers / shower | SW | Hansgrohe (or equal: GROHE) | Prefer authorised dealers for warranty |
| Wet floor/wall tiles | FL / WT | ASA Tiles / local porcelain (or equal) | Same factory/batch for adjacent wet zones; R10+ wet |
| Adhesive / grout | AD | Mapei / ARDEX / Bostik (or equal) | Anti-mould grout in wet; match waterproof brand family if possible |
| Waterproofing | WP | Sika / Mapei / ARDEX / Bostik wet system (or equal) | Flood test before tiling (checklist) |
| LED track / modules | LG | Philips / local 48V magnetic (or equal) | Target 3000K, CRI≥90 |
| Cove LED | LG | 24V tape + Alu profile + diffuser | Drivers accessible; wet IP as required |
| Wet downlights | LG | IP44+ (or higher in shower zones per position) | Confirm with electrician / CoP |
| Fire door set | DR-FD | Certified FD set (rating per drawing / AHJ) | Chain `interior-fire-life-safety`; no appearance-only substitute |
| BS faceplates | EL | Schneider AvatarOn (or equal) | BS 1363 sockets; splash covers near wet |
| Metal colour | MT | One flat-wide finish (e.g. matt black **or** champagne) | Powder coat / PVDF preferred over weak spray |

## Substitution language

When proposing alternates: state performance equivalency (thickness, IP, R-rating, formaldehyde class, fire certificate) and programme impact. Budget-driven swaps → `interior-value-engineering` G-B-B + this file for or-equal check.
