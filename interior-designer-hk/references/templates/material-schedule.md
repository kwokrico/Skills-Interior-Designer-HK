## 5. 總則 General Notes (soft checklist)

Designer practice checklist — **suggest and document**, do not invent new compliance hard stops. Full list: [`general-notes-checklist.md`](../../subskills/interior-material-procurement/references/general-notes-checklist.md).

- [ ] Sample / data sheet / mock-up approval before order and install
- [ ] Site remeasure; drawings are design/quote reference only
- [ ] Low-formaldehyde boards (E1 / equivalent) + test report request
- [ ] Low-VOC paints/adhesives/sealants + SDS where relevant
- [ ] Wet-area joinery: HMR / moisture-resistant carcass; seal cut-outs
- [ ] Wet floor tiles: slip data (typ. R10+; shower consider R11) + falls to drain
- [ ] Wet tile adhesive + anti-mould grout suited to substrate and tile absorption
- [ ] Tempered glass + edge polish for doors/high glass; supplier confirms thickness/fixings
- [ ] Metals: corrosion-resistant in wet zones; whole-flat metal colour unified
- [ ] Estate / BD / FSD implications flagged for kitchen/bath/fire-separation changes
- [ ] Locked design intent called out (e.g. SPC vs full ceramic; Corian vs quartz; Alu strip width)
- [ ] Lighting: consistent CCT (e.g. 3000K), CRI≥90 target; drivers accessible
