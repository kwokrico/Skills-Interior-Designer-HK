## Summary

- 價錢差在做法，唔係同一塊板
  - 片題講同一塊夾板可以貴一倍；簡介同口播講訂造傢俬用甲板，關鍵係做法
  - Andrew：上一集講過 E0、E1、ENF 甲板、焗油纖維板、刨花板；板材影響冇做法咁大
  - 好多公司而家唔會講明用二合一、三合一定釘裝，因為客人分唔到
- 收口傢俬點解貴
  - 櫃裝完之後再度尺寸、解收口，跟足現場
  - 可能裝完再拆、拆完再裝，要做兩次，工藝同做法都多
- 釘裝
  - 以前的做法，比較穩陣
  - 廠裡木工開料、釘櫃殼，再黐飾面，似現場做櫃
  - 分別：現場係手工黐面同封邊；廠可以用機器封邊同切割，地方大啲，效果好啲
  - 要大工，尤其開料的人係以前傢俬廠最貴的人
- 二合一同三合一
  - 而家好多訂造櫃用呢種，唔使成個櫃搬去現場
  - 三合一似 IKEA 或者淘寶：板入面膠塞、螺絲、再加一粒偏心輪（口播「大餅」），幾件扣埋成櫃
  - 二合一類似，兩塊板入榫或者卡扣
  - 板可以拆散運送，安裝簡單，普通技工都裝到櫃身，最多再做收口
  - 繪圖員畫好，電腦計料、配件同尺寸，機器開料，技工組裝，人工慳好多
  - 口播話廠裡成本比起釘裝可以差大約一半
  - 通常用生態板，出廠已經有飾面，唔使再貼面，再平一截
  - 限制：只適合簡單、平板、直角；弧形、S 形、斜邊卡扣唔到，要改返釘裝
  - 公司原本當你做二合一或三合一，你要特別造型，附加費會多
  - 結構上牆之後唔會差好遠，但價錢差好遠；設計公司未必把省到的成本減價畀你
- 點揀同點問
  - 預算有限、以實用為主，可以考慮二合一或三合一，性價比高
  - 要特別造型先問做唔做到、附加費幾多；之後的後加項目價錢可以差好大
  - 唔好只問包甲板定生態板，大家都包；要問做法
  - 睇唔到的位置唔使做到一百分：櫃遮住成幅牆，後面的磚從來睇唔到；新樓交樓的廚櫃、吊櫃、鏡櫃後面好多時冇磚

## Items

**傢俬做法**

1. **收口** — 櫃裝完再度現場尺寸做收口，可能要拆裝兩次，所以貴
2. **釘裝** — 廠裡開料、釘櫃殼再貼面，要大工，適合弧形、斜邊同特別造型
3. **三合一** — 膠塞、螺絲同偏心輪扣埋，似組裝傢俬，易運易裝
4. **二合一** — 兩塊板入榫或者卡扣，同樣可以拆板運送
5. **生態板** — 二合一、三合一常用，出廠已有飾面，省貼面工序

**問公司**

1. **做法** — 問用釘裝、二合一定三合一，唔好只問板材
2. **特別造型** — 問做唔做到，同附加費會唔會因為改釘裝而大增
3. **睇唔到的工序** — 櫃背後的磚如果永遠睇唔到，可以唔使全部換新
