## Summary

- 大型屋苑維修常出現開標價很平、埋單變天價。他借這類新聞講一個工程狀況，不點名是哪個屋苑，也不評論單一事件
  - 評標通常分 Technical 和 Commercial。技術分看公司背景、資歷和過往經驗；商業分基本上是價錢越平分數越高
  - 商業標常用 BQ（Bill of Quantities），投標公司照同一張清單填價
  - 真正容易出問題的不是正常 BQ，而是 Optional Item；片中說有些合約會把它寫成 Session Subject to Exist。意思是這些項目未必一定做，但如果要做，價錢已經寫好
- Optional Item 可以讓總價看起來最低，開工後卻變成不能拒絕的追加
  - 評標的計分方法常常不把 Optional Item 算進總價
  - 有人把核心工程填得很平，Optional Item 填天價，總價仍然最低、分數最高
  - 現場一旦觸發這些項目，就要按合約的高價收費；工程已經開始，業主實質上沒得重選
- 大維修至少有一張標準 BQ，大家填同一張表，Optional Item 的問題還有方法避開。裝修更難比，因為根本沒有標準 BQ
  - A、B、C 三間公司三張報價，包含的內容不同，Optional Item 也不同
  - 還要看哪些不包、物料包不包、哪些寫「到時先算」
  - 一般業主很難直接比較
  - 描述裡的例子是開頭平二十萬，最後可以再補到四、五十萬。片中也說簽約時看到的價錢，做到後來可以變成三十萬、四十萬甚至更高；多出來的裡面，一部分是物料，一部分是可選項目
- 比較裝修公司不要只看總數，要看有多少項目沒講清楚、有多少潛在補價、用什麼級別的物料、有多少是 Optional Item
  - 最貴的從來不是一開始見到的那個價，而是開工後你沒得拒絕的那一刻

## Items

**比較裝修報價**

1. **工程和物料分開看** — 每間公司包的物料都不一樣，先把物料從工程價裡勾出來，才看得出合約之間的價錢差在哪。
2. **看物料級別和誰來買** — 物料有低價、中價、高價，可能是淘寶貨、西班牙或意大利貨，也可能來源不清楚。業主可以自己選、自己買，或不買。
3. **必須做但未寫價的工程要問實** — A 公司可能已包並估了價，B 公司沒寫所以看起來更平，但範圍少了。問 B：如果要做這堆項目，價錢是多少，哪怕先列成 To be confirmed。
4. **比較各公司的可選項目** — 可選項目要看 A、B、C 是不是包含同一類東西，不要只比已經寫死的總價。
5. **設計差異自己計分** — 例如一間有燈槽、另一間沒有。技術部分和價錢部分分開加分，先定自己的購買計劃，再比較哪間值得信。
