# HKRIDA collection — source and coverage index

Reviewed 2026-11-06. Seven local PDFs, 486 PDF pages. The folder name is **HKRIDA**; the publications identify **HKIDA (香港室內設計協會)** and Hong Kong Polytechnic University as publisher/research partners. RIDA refers here to the registration project discussed in the guideline, not a statutory approval authority. Use the publications' actual titles below. Filename upload dates are not publication dates.

Sources and page-numbered text extracts are archived in [SS/HKRIDA](SS/HKRIDA/). Page references below are **1-based PDF pages**, not printed folios: the 2014 PDF contains two-page spreads. Text extraction does not preserve table columns or image-only content. The extraction manifest lists page text lengths and short/image-only pages; selected textless substantive pages are also preserved as readable PNG extracts. The original PDF remains authoritative.
